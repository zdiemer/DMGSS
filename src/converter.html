The caveat

Conversion uses Python on the server, outside the browser. The generated emulator runs entirely in HTML/CSS. The converter encodes bytes; it does not execute the ROM or precompute an execution trace.

Small diagnostics only: 32 KiB unbanked ROMs, or raw programs up to 4 KiB. At most 1,024 bytes may differ from the ROM’s most common padding byte; denser files are rejected to bound CSS size.

Your file is sent to this server for conversion. Uploads and generated pages are not retained; temporary files use memory storage. Downloaded HTML contains the encoded ROM. Use the offline command below to keep conversion on your own machine.

Import is not game compatibility.

The CPU supports 243 unprefixed and 256 CB-prefixed instructions, 64 bytes of work RAM, 127 bytes of high RAM and one VRAM tile. Instruction-duration accounting, software-requested interrupts, DI/EI/RETI and the HALT bug are supported. DIV/TIMA/TMA/TAC can request timer interrupts and wake HALT. Full graphics, serial, joypad, audio, cartridge banking and precise bus timing are still missing. CPU registers start at zero except PC at 0100; IF reads E0, TAC reads F8 and IE is zero; there is no boot ROM. Unsupported instructions and addresses show CPU TRAP.

Compatible mode is the best first check. Automatic mode needs working scroll timelines; Linux WebKit tests do not certify every iOS device.

Convert offline

From a checkout of DMGSS, using Python 3.11 or later:

python3 tools/convert.py demo.gb -o demo.html
# For a raw diagnostic program:
python3 tools/convert.py demo.bin --format raw -o demo.html

Open the generated HTML file in a supported browser. It includes its styles and ROM and makes no network requests while running. Mobile file viewers may preview HTML rather than open it as a browser page; Convert & run avoids that extra step.
