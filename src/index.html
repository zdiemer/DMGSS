T-cycles count instruction and interrupt-entry durations, wrapping at 65,536. This is emulated work, not browser time. Timers also advance while HALT waits; those idle clocks are excluded here. Bus timing is still approximate.

A different kind of console.

The clock and state live in your browser’s stylesheet engine. No JavaScript. No hidden emulator.

Streaming mode needs Chromium. Chrome on iOS uses WebKit, just like Safari. Try compatible mode for a bounded, CSS-only run on WebKit.
  • Embedded diagnostic: loads, arithmetic, branches and RAM.
  • Tile lab: a pointer loop copies an original 8×8 tile from ROM into VRAM.
  • Stack lab: nested subroutines save registers and return through RAM.
  • ALU lab: decimal arithmetic, carry flags, bitwise logic and rotations.
  • Bit lab: rotations, shifts and bit operations on registers, RAM and VRAM.
  • High RAM: restart vectors, stack returns and code written into RAM.
  • Interrupts: software requests, priority, delayed enable and the HALT bug.
  • Timers: DIV/TIMA/TMA/TAC, overflow requests and waking from HALT.
  • Full graphics hardware, games and joypad input are still in development.
  • Reset reloads the machine. Nothing is saved.
